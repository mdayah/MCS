# VBTOO - MicroHelp VBTools 3

## Overview

This directory contains **MicroHelp VBTools 3** (August 1993), a commercial third-party component library for Visual Basic. Note: This is for **Windows** Visual Basic, not MS-DOS VB, and appears to be archived here for reference rather than active use.

## Directory Structure

```
VBTOO/
├── SETUP.EXE           # Installation utility (32K)
├── VBT300.HL_          # Compressed help file (675K)
├── VBTOOLS.LIC         # License file
├── READ.ME             # Documentation (16K)
├── MHMASK.INI          # Configuration
├── LZEXPAND.DLX        # Compression library
├── *.VB_               # Compressed VB controls
└── *.DL_               # Compressed DLL files
```
